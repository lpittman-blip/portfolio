Artemis 567885: self-expanding sparse MoE

A CPU-first Top-K MoE transformer in PyTorch. The engine adds experts, layers and capacity when training stalls, and a supervisor AST-checks, time-limits and rolls back bad changes.

GPU training runs

A 48.8M-parameter dense Artemis LM trained on a rented RTX A6000 (50 min, 374M tokens). It used a staged pretrain followed by assistant-only SFT, with held-out evaluation in bits per byte.

3.293 → 1.191 bits/byte on held-out web text · $0.44 measured spend

Fine-tuning pipeline with cost guards

QLoRA fine-tunes of a 7B and a 30B model on 2-GPU instances. Each run has a hard dollar cap, a host-side kill timer, an on-instance self-destruct, and teardown verified by instance ID.

Caps $5 / $15 · real spend $0.53 / $1.08

Ops dashboard and Ops Terminal on Azure

A password-protected ops dashboard on Azure Container Apps with bcrypt login, signed sessions, a strict CSP, rate limits and Blob-backed daily snapshots. The Ops Terminal is a sandboxed command API for agents with JSON in/out, timeouts, a command policy, secret redaction and an audit log.

Refreshes daily · access is private

Byte-level MoE language model

Tokenizer-free: raw UTF-8 bytes go through causal MoE blocks to a next-byte softmax. It was trained on CPU on Project Gutenberg and evaluated on authors it never saw in training.
